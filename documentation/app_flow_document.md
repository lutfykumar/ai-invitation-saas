# App Flow Document

## Onboarding and Sign-In/Sign-Up

When a new user lands on the application, they first encounter a clean landing page that briefly describes the digital invitation service. A clear signup button invites them to create an account. Tapping this button takes the user to the registration page, where they enter their name, email address, and a chosen password. After submitting the form, the user receives a confirmation email with a link that they must click to verify their account. Once verified, they can return to the app and sign in using their email and password. If users forget their password, they click a “Forgot Password” link on the sign-in page, enter their email address, and receive a password reset link. By following the link, they set a new password and then return to the sign-in page to log in. To sign out, users click their profile icon in the header and select “Sign Out,” which safely ends their session and returns them to the landing page.

## Main Dashboard or Home Page

After signing in, users arrive at the main dashboard. The screen is divided into a left-hand sidebar and a central content area. The sidebar lists options such as “My Invitations,” “Create New Invitation,” “Themes,” and “Account Settings.” At the top, the header displays a greeting with the user’s name and a profile icon that opens a menu for signing out. In the main pane under the header, a welcome message and quick-action cards invite users to start a new invitation or explore themes. A table below the quick actions shows any existing invitations with columns for invitation title, event date, status, and actions like edit or view. From here, users can click any navigation link or table action to move to other parts of the application.

## Detailed Feature Flows and Page Transitions

When a user clicks “Create New Invitation,” they move to the invitation setup page. Here, the user first chooses an event category such as wedding, birthday, or meeting from a dropdown. Next, they pick a design theme by clicking through visual theme cards. After selecting a category and theme, they click “Continue” and enter event details including title, date, time, and location in simple form fields. Underneath the form, an AI assistant panel offers to generate invitation text. By clicking “Generate Text,” the AI assistant streams suggestions into a text area, where the user can accept or refine the content. Once the text is ready, a live preview on the right updates to show how the final invitation will look. The user clicks “Save Draft” to store their invitation or “Publish” to make it public.

To edit an existing invitation, the user goes to “My Invitations” in the sidebar. The table of invitations lists all saved items. Clicking the edit icon beside an invitation loads the same editor page, populated with the invitation’s data. Users can change details, update AI-generated text, and see the live preview update. After editing, clicking “Save” updates the record and returns the user to the dashboard.

Viewing a published invitation happens when a user clicks the view icon in the table or shares the public link. This navigates to a dynamic, public-facing page at `/invites/{inviteId}`. That page loads on the server, fetches the invitation data, applies the selected theme’s styles, and renders a polished invitation that guests can see without signing in.

Exploring themes is done by clicking “Themes” in the sidebar. On the themes page, users scroll through available designs, each showing a preview image and name. Clicking a theme opens a detail page where they can preview the theme in larger view and then choose to apply it to a new or existing invitation.

Administrators access the admin panel by visiting the `/admin` path. After signing in with elevated privileges, they see pages for managing themes and categories. To add a theme, the admin fills in a name, uploads preview images, and defines CSS variable settings. To add a category, they simply provide a category name and optional icon. Changes here immediately become available in the user-facing theme and category selectors.

## Settings and Account Management

Users manage their personal information under “Account Settings” in the sidebar. On this page, they can update their display name and email address. A separate section allows them to change their password by entering the current password and entering a new one twice for confirmation. If the application offers subscription-based features, a billing section displays the current plan, recent invoices, and a link to update payment information. After making any changes, users click “Save Settings,” receive a confirmation message, and can then use the sidebar to return to the dashboard or start another flow.

## Error States and Alternate Paths

If a user submits invalid information, such as leaving a required field empty or selecting a past date, the form shows a red inline message beneath the offending field. When the AI assistant fails to generate text due to a network error or server issue, a banner appears above the editor stating, "AI generation failed. Please try again." The user can click “Retry” to call the AI again or manually edit the text. If the user loses connectivity during saving or publishing, a toast notification warns of the failed action. The user can then retry the operation once their connection is restored. Attempting to access an invitation that does not exist or one they do not own redirects to a friendly error page that explains the invitation cannot be found and offers a link back to the dashboard.

## Conclusion and Overall App Journey

From first arriving on the landing page to sharing a completed invitation link, the user journey is smooth and guided. A new user signs up with their email, verifies their address, and logs in. Onboarding quickly leads them to the dashboard where they can create an invitation by selecting a category and theme, entering event details, and using AI-powered text suggestions. They save or publish invitations, manage them from the dashboard, and share a public link for guests. Along the way, they can update personal settings, recover a lost password, and explore new themes. Administrators extend the service by adding themes and categories through a dedicated panel. Throughout, clear error messages and retry options keep users on track, delivering a cohesive experience from sign-up to daily use and beyond.
